# AskPupkin

Проект вопросов и ответов (аналог StackOverflow), разрабатываемый в рамках курса по Web-разработке.

## Описание проекта
AskPupkin — это платформа, где пользователи могут задавать вопросы по программированию, отвечать на них, ставить оценки и искать нужную информацию по тегам.
На данном этапе реализована статическая верстка страниц и базовая структура Django-проекта.

## Технологии
* **Backend:** Django 5 (Python 3)
* **Frontend:** HTML5, CSS3, Bootstrap 5

## Реализованные страницы
В рамках первого этапа сверстаны и интегрированы в шаблоны Django следующие страницы:
1. `Главная страница` — список новых и популярных вопросов.
2. `Страница вопроса` — детали вопроса, форма ответа и список ответов с галочками "Correct!".
3. `Поиск по тегу` — вывод всех вопросов, связанных с выбранным тегом (например, "css").
4. `Задать вопрос` — форма для публикации нового вопроса с валидацией.
5. `Авторизация` и `Регистрация` — формы для входа и создания нового аккаунта.
6. `Профиль` — настройки данных пользователя и загрузка аватара.

## Навигация по проекту (Доступные URL)
После запуска сервера все сверстанные страницы будут доступны по следующим адресам:
* `http://127.0.0.1:8000/` — Главная страница со списком новых вопросов (`index.html`)
* `http://127.0.0.1:8000/hot/` — Список лучших вопросов (`hot.html`)
* `http://127.0.0.1:8000/ask/` — Форма создания нового вопроса (`ask.html`)
* `http://127.0.0.1:8000/question/1/` — Страница конкретного вопроса и ответы (`question.html`)
* `http://127.0.0.1:8000/tag/css/` — Список вопросов по конкретному тегу (`tag.html`)
* `http://127.0.0.1:8000/login/` — Форма авторизации (`login.html`)
* `http://127.0.0.1:8000/signup/` — Форма регистрации (`signup.html`)
* `http://127.0.0.1:8000/profile/` — Настройки профиля пользователя (`profile.html`)

## Запуск проекта

Склонируйте репозиторий:
```bash
git clone [https://github.com/GrayMouse9/2026-VK-EDU-Web-13-Shpakova-D.git](https://github.com/GrayMouse9/2026-VK-EDU-Web-13-Shpakova-D.git)
cd 2026-VK-EDU-Web-13-Shpakova-D
```

### Вариант 1. Локальный запуск:

Создайте и активируйте виртуальное окружение: `python -m venv venv, затем source venv/bin/activate (Linux/Mac) или venv\Scripts\activate (Windows).`

Установите зависимости: `pip install -r requirements.txt`

Запустите сервер: `python manage.py runserver`

### Вариант 2. Запуск через Docker Compose:

Убедитесь, что Docker запущен на вашем компьютере.

Выполните команду в корне проекта: `docker compose up --build`
