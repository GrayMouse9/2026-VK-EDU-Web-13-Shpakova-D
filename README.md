# AskPupkin 🚀

Проект вопросов и ответов (аналог StackOverflow), разрабатываемый в рамках курса по Web-разработке.

## 📄 Описание проекта
AskPupkin — это платформа, где пользователи могут задавать вопросы по программированию, отвечать на них, ставить оценки и искать нужную информацию по тегам.
На данном этапе реализована статическая верстка страниц и базовая структура Django-проекта.

## 🛠 Технологии
* **Backend:** Django 5 (Python 3)
* **Frontend:** HTML5, CSS3, Bootstrap 5
* **База данных:** SQLite (встроенная для разработки)

## 📌 Реализованные страницы (ДЗ 1)
В рамках первого этапа сверстаны и интегрированы в шаблоны Django следующие страницы:
1. `Главная страница` — список новых и популярных вопросов.
2. `Страница вопроса` — детали вопроса, форма ответа и список ответов с галочками "Correct!".
3. `Поиск по тегу` — вывод всех вопросов, связанных с выбранным тегом (например, "css").
4. `Задать вопрос` — форма для публикации нового вопроса с валидацией.
5. `Авторизация` и `Регистрация` — формы для входа и создания нового аккаунта.
6. `Профиль` — настройки данных пользователя и загрузка аватара.

## 🚀 Как запустить проект локально

1. Склонируйте репозиторий:
   ```bash
   git clone <ссылка_на_ваш_репозиторий>
   cd web
   ```

2. Создайте и активируйте виртуальное окружение:

```
python -m venv venv
source venv/bin/activate  # Для Linux/macOS
# venv\Scripts\activate   # Для Windows
```
3. Установите зависимости (пока требуется только Django):

```
pip install django
```
4. Запустите сервер разработки:

```
python manage.py runserver
```

5. Откройте в браузере адрес: http://127.0.0.1:8000/
